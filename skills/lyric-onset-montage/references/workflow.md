# 工作流：27 步

每步写 **输入 → 动作 → 产物**，最后一列是「失败长什么样」——出了问题先来这里对号。

---

## A 立项

### 1. 开工提示词
- **输入**：音乐路径 / 媒体流路径；素材目录路径；范围。
- **动作**：读目录、数素材、读时长；先报「歌 / 时长 / 素材条数 / 建议范围」，再开工。
- **产物**：一条开工确认。
- **失败**：直接下刀没报数 → 用户不知道你盘了什么，后面每步都要重新解释。

### 2. 范围与结尾点
- **输入**：整首 / 半首 / 副歌一段 / 到某句。
- **动作**：确定截点；把结尾止点放在下一个字头前 0.3–0.4 秒。
- **产物**：范围 + 截点秒数。
- **失败**：范围中途改 → 分镜重排；余量不够 → 末尾漏半个字。

### 3. 取音频
- **输入**：本地音乐文件、已下载的媒体、用户给的链接。
- **动作**：抽音频（带封面图流的视频加 `-vn -map 0:a:0`）；确认开头有没有数字静音。
- **产物**：48k 立体声 m4a/wav（原始质量）。
- **失败**：拿分析用的 16k 单声道去合曲，出片才发现；开头 2 秒静音照剪，成片开场是无声画面。

### 4. 素材盘点（按规模自适应）
- **输入**：素材目录。
- **动作**：先数条数与最长单条时长，再决定精细度：
  - ≤5 条且单条 ≤10 分钟 → 直接精查，不打扰用户。
  - ≤3 条但有一条 >10 分钟 → 问一句要不要精查，附预估时间。
  - 6–20 条 → 精查，开工时报预估时间。
  - >20 条或总时长 >2 小时 → 建议先粗查（每 5 秒一帧只出候选区间），报预估时间并问要不要精查。
  - 精查 = 每 5 秒一帧 → 候选区间按 1 秒抽帧 → 窗口精确到 ±1 秒 → 每条 2–3 个标签。
- **产物**：`素材清单.md`（文件 / 窗口 / 标签 / 一句描述）。
- **失败**：用「十几秒一帧」粗查然后照着它写窗口；预估时间不报，用户以为卡住了。

### 5. 环境体检
- **输入**：本机。
- **动作**：`ffmpeg -version`、`ffprobe -version`、Python 版本、numpy/scipy/matplotlib、剩余磁盘。
- **产物**：一行体检结果。
- **失败**：跑到体检脚本才 `ModuleNotFoundError`；`ffprobe` 不存在而脚本默认它在。

## B 时间轴

### 6. 歌词来源
- **输入**：音频/视频自带 SRT·LRC；画面烧录字幕；网络歌词站。
- **动作**：三源并列收集，逐句比对；不一致的地方标出来。
- **产物**：定稿歌词文本（逐句）。
- **失败**：单源采信 → 串歌、漏句、改词（同一部剧的多首主题曲最容易串）。

### 7. 句界
- **输入**：字幕 / 字幕轨 / 烧录字幕段。
- **动作**：按字幕条目定句界；**短于 1.0 秒的条目并入相邻句**；括号里的内容按「是否与主唱同时、时长、有无气口」三条件判断，不按括号本身判断。
- **产物**：`句子表`（序号 / 文本 / 起止）。
- **失败**：把 0.6–0.9 秒的短条目当独立句各切一刀 → 碎刀。

### 8. 字头实测
- **输入**：音轨 + 句界（±0.45 秒窗）。
- **动作**：300–3000Hz 带通 + 10ms RMS 包络，找上升起点；有气口 → 谷尾 +2 帧；无气口 → +0.15 秒并标 `⚠ 待确认`。
- **产物**：每句切点候选。
- **失败**：用峰值（落在元音上，晚 0.1–0.3 秒）；无气口句直接定死，用户听出「早」。

### 9. 辅助校验
- **输入**：同上。
- **动作**：谱通量、拍网格、词级时间戳各自算一遍，只用来缩窗、交叉看数量级。
- **产物**：对照表（可选）。
- **失败**：把辅助方法的结果当终值；拿同一个检测器既定切点又当验收。

### 10. 时间基准
- **输入**：成片音轨（或镜头表秒数）+ 原曲。
- **动作**：10ms 包络互相关解偏移，报相关系数；r>0.9 才认。
- **产物**：`成片 0s = 原曲第几秒`。
- **失败**：成片秒 / 原曲秒混用 → 整表漂几十秒，结论直接反。

### 11. 字头表落盘
- **输入**：上面全部。
- **动作**：逐句一行，带口径与置信度。
- **产物**：`字头表.csv`（序号 / 文本 / 原曲秒 / 口径 / 置信度）。
- **失败**：只在聊天里贴数字 → 返工时没有基准可比。

### 12. 三角互证
- **输入**：字幕起点、能量起音、词级时间戳。
- **动作**：三个口径分开登记，逐句比对；差 >0.2 秒的句子单独列出来请用户听。
- **产物**：待确认清单。
- **失败**：把三个口径混算成一个「平均偏差」，得出假的系统性提前。

## C 选材

### 13. 挑候选
- **输入**：`素材清单.md` + 歌词句。
- **动作**：按标签给每段 3–4 首选 + 3–6 备选，统一格式 `文件@入点-出点`，各写一句理由。
- **产物**：候选表。
- **失败**：单方案 → 一句不对整片重排。

### 14. 抽帧复核
- **输入**：候选窗口。
- **动作**：每条抽首 / 中 / 末帧；看主体是否清楚、头脸有没有被切、是不是照片、有没有字牌。
- **产物**：复核记录（改过的窗口）。
- **失败**：照抄索引描述（实测 18 个镜头里 5 处与画面对不上）；入点只露半张脸。

### 15. 语境核对
- **输入**：候选镜头的原片上下文。
- **动作**：想一遍「这段在原片里前后是什么」，会引出不相干叙事的换掉。
- **产物**：换过的候选。
- **失败**：为了画面里有某个物件，借了会讲出另一个故事的镜头。

### 16. 预览
- **输入**：候选表。
- **动作**：出低码率预览 + 首帧拼图（编号从 1）；拼图一屏看完。
- **产物**：预览文件 + 拼图。
- **失败**：不预览就下刀，糊素材 / 电话牌 / 压人头都是这时候才该发现的。

### 17. 用户点头
- **输入**：预览、拼图、拿不准的几段。
- **动作**：逐段确认；把「这两段我拿不准」单独列出来问。
- **产物**：定稿候选。
- **失败**：替用户拍板；或者在索引里逐条追问，把人问烦。

## D 出片

### 18. 分镜表
- **输入**：定稿候选 + 切点。
- **动作**：一行一刀，列 **序号 / 切点 / 时长 / 歌词 / 情绪 / 素材 / 入点 / 理由**；反推时长后做无缝化。
- **产物**：镜头表。
- **失败**：有空档 → 成片比音频短；刀太密 → 一闪而过。

### 19. 逐刀验算
- **输入**：镜头表 + 源片时长。
- **动作**：每刀验 `入点 + 该刀时长 ≤ 源片时长 − 1/30`。
- **产物**：校验通过的表。
- **失败**：算到压在源片末帧上，`-frames:v` 只出 FR−1 帧，看着像 concat 丢帧。

### 20. 切镜头
- **输入**：镜头表。
- **动作**：`-ss 入点` + `-frames:v FR`；1080p30；竖屏垫模糊底；`-an`。
- **产物**：`cuts/cXX.mp4`。
- **失败**：用 `-t` 累计漂移；`eq=brightness` 压太狠变成黑边；滤镜带标签却用 `-vf`。

### 21. 拼接 + 合曲
- **输入**：切片 + 原始音频。
- **动作**：`-f concat -c copy` 拼接 → 核 `nb_frames` → `-map 0:v -map 1:a -t {总时长}` 合曲；结尾淡出在 mux 时加。
- **产物**：成片。
- **失败**：`-c copy` 丢帧（154→151）；`-shortest` 截尾；淡出烘进切片，复用该段时中途变黑。

### 22. 体检
- **输入**：成片 + 镜头表。
- **动作**：`check_cut.py`：A/B、帧数差、末段电平、首帧拼图；竖屏刀量两侧 300px 均值。
- **产物**：自检报告。
- **失败**：跳过脚本，「看着对」就交；脚本红了还继续。

## E 交付与迭代

### 23. 交付
- **输入**：成片、镜头表、首帧拼图、自检报告。
- **动作**：五件一起落盘（成片、分镜首帧、镜头表、自检报告、`改动台.html`）；客户端支持就把成片与分镜图直接显示在对话面板，边看边对照。
- **产物**：交付目录。
- **失败**：只交成片，文档晚一轮才补。

### 24. 收改动
- **输入**：用户的话。
- **动作**：分清是「某一处不对」还是「整片不对」；按「分镜几」或「几分几秒」定位。
- **产物**：改动清单。
- **失败**：把「洗一版」理解成推翻重做；按错编号改到没被点名的镜头。

### 25. 最小改动
- **输入**：改动清单。
- **动作**：只改那几行、只重切那几刀（`cut:N`），其余切片复用；concat + mux 重出。
- **产物**：新成片 + 「其余没动」的证据（切片 mtime、帧数）。
- **失败**：不带参数跑全量 `cut` 或 `all`，白等十几分钟还可能引入新的取整差异。

### 26. 改动台账
- **输入**：本轮改动。
- **动作**：每条写「反馈 → 原来 → 现在」，同步镜头表与自检报告。
- **产物**：台账。
- **失败**：只改成片不改表，下次拿表来问时对不上。

### 27. 回写索引
- **输入**：本轮的弃用理由。
- **动作**：整条禁用写 `⛔ 整条禁用（原因；日期）`；单窗口写 `⛔ 288–292s 禁用（原因；日期）`。
- **产物**：更新后的索引。
- **失败**：只改这一版成片，下一首歌又挑到同一段。
