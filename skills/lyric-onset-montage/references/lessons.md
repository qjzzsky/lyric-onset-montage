# 坑：27 条

每条一句原因 + 违反之后的后果。都是真实项目里踩出来的，不是设想。

## 时间轴（9）

1. **把 LRC / 字幕行时间当字头。** 字幕是对轴出来的，普遍比歌声早 0.1–0.27 秒 → 整片每一刀都早，用户会说「每句开头都切早了」。
2. **拿字幕时间当尺子去核切点。** 两个口径混算，会得出「刀口系统性提前」的假结论 → 先分口径登记（字幕起点 / 能量起音 / 词级时间戳）。
3. **指望 whisper 定时间。** 唱词上它会连段、会幻觉，整段起点粘在一起，偏 0.4–1.1 秒 → 字头必须用能量法量，whisper 只认字。
4. **以为检测器报的起音就是字头。** 实测比人耳接受的位置早 0.15–0.25 秒，且修正量不恒定（+250 / +400 / +650 毫秒都出现过）→ 只能出候选，分层定：有气口切谷尾 +2 帧，无气口标待确认。
5. **拿单刀 A（切点−字头）迭代。** 切点一动，检测器在附近取的最强起音也跟着动 → 同一句在不同版本能报出 −457 / +380 / +170 毫秒。
6. **验证基准与切点同源。** 切点抄 whisper、字头也来自 whisper，对账「全绿」只是自证 → 独立基准只能来自外部已验证版本，或请用户人工定位。
7. **在满混音上看频谱图定字头。** 人声谐波被鼓/贝斯/吉他的宽带能量淹掉，几十毫秒分辨率图上只看得出「这里有一团能量」。
8. **测速不做亚采样插值。** 1 帧的 lag 量化在几分钟的曲子上能累计漂几秒，相位集中度直接归零，看着像「这首歌没有节拍」。
9. **测相位前不剔衬词/念白/喊声。** 非唱内容把相位集中度稀释近 5 倍（实测剔除后 R 0.26→0.47）→ 读数看着像「没有节拍」。

## 素材与选材（6）

10. **照抄索引/清单里的窗口。** 粗查时的描述会错（实测 18 个镜头里 5 处与画面对不上）→ 下刀前必须抽那一帧定案。
11. **信 `ffprobe` 的 rotation 标记。** 真竖屏会报成 1920×1080，也有带标记但画面本来就横的 → 抽一帧看实际尺寸。
12. **把照片当视频用。** 相册合成素材里常混照片 → 同一条隔 3 秒两帧完全一样即可识破。
13. **不看原片语境。** 一个不起眼的镜头在原片里可能是接站、是访谈里的半句话 → 塞进混剪会引出不相干叙事。
14. **用打码解决「不能用」。** 电话牌、车牌、二维码、发糊素材，打码是返工 → 换窗口一次解决。「不能用」不等于「不好看」。
15. **题材取舍交给使用者。** 使用者点名不要的题材，或会让画面引出与歌词无关联想的镜头 → 换中性空镜，别为「悲伤」硬凑画面。

## ffmpeg 与结构（8）

16. **用 `-t 时长` 切。** 会取整到帧边界，多刀累计会飘 → `round(t*30)` + `-frames:v`。
17. **入点压在源片末帧上。** `-frames:v FR` 只出 FR−1 帧，全片少 1 帧，看着像 concat 丢帧 → 逐刀验「入点 + 时长 ≤ 源片 − 1/30」。
18. **信 `-c copy` 拼接。** 会丢帧（实测 154→151）→ 拼完核 `nb_frames`，少了整段重编码。
19. **合曲用 `-shortest`。** 容器时长看着对，帧数少 3 → 显式 `-t {总时长}`。
20. **用 `-ss (t±1/30)` 取切点前后两帧。** `-ss` 取整到帧，两个时间点常落到同一帧，误判「没换镜」→ `select='eq(n,N)'` 按帧号取。
21. **把 `eq=brightness` 当按比例压暗。** 它是整体加减：−0.45 = 全画面减 115 级，暗部直接归零，两侧变纯黑 → 压暗后量两侧 300px 均值，15–110 才算有垫底。
22. **滤镜串带标签还用 `-vf`。** 报 `Output with label 'v' does not exist` → 有 `[标签]` 一律 `-filter_complex` + `-map [v]`；一条命令写两个 `-vf` 后一个会静默覆盖前一个。
23. **时间轴留空档。** 视频比音频短、结尾被截 → 每刀延到下一刀起点，首刀从 0 铺满，末刀收到截点，拼完比时长（差 >0.15 秒就是有空档或丢帧）。

## 协作与验收（4）

24. **每段只给一个方案就下刀。** 一句不对就得整片重排重渲（有过改了 11 轮的记录）→ 候选表给 3–4 首选 + 3–6 备选。
25. **把「重新洗一版」当成推翻重做。** 它只指重新渲染同一份分镜 → 拿不准就先说一句「我按只改这一刀来做」。
26. **按刀号沟通。** 图注与镜头表曾差 1，照号改会整体错一刀 → 编号一律从 1 起、两处同号；报改动用「秒数 + 画面」。
27. **文档晚一轮才补。** 长任务会被轮数上限或中断截断 → 成片、镜头表、首帧图、自检报告边生成边落盘。
