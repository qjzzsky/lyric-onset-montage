# 选材：跟歌词贴合，其余是开关

---

## 一、唯一硬标准：跟歌词贴合

- 贴合的空镜、环境镜可以用（桥、斑马线、跑道、环廊都行）；不必每个镜头都有人。
- 有人时抽 3 帧（含入点那一帧）确认人清楚、头和脸没被画框切掉；入点只露半张脸就往后挪到主体完整入镜。
- 镜头里别压着一颗路过的人头。

## 二、情绪对位（默认开，可关）

方向而不是死映射表：**画面情绪与歌词情绪同向**。

| 歌词 | 画面方向 |
|---|---|
| 消极 / 吃力 / 受阻 | 真卡住、真用力、行动受限、疲惫特写 |
| 积极 / 光 / 胜利 | 走得通、有人帮、抵达、欢呼、旗帜、灯光 |

三条经验：

1. **这是方向，不是物件清单**：不必为「悲伤」硬凑某个题材；找不到就换中性空镜。
2. **积极/消极不跟场景的「设施属性」绑死**：一个说明「社会能让人出行」的画面，别压在黑暗句下面。
3. 用户说「别配这么沉的」/「对位关掉」就按说的改，这条不是硬规定。

## 三、语境干净（个别情况，问一句）

判断不了的部分不要靠规则穷举，靠问：

- 这段在原片里前后是什么？（接站、欢迎、访谈里的半句话，塞进混剪会引出不相干叙事）
- 画面里有人、有牌、有可读文字：
  - 车牌 / 电话 / 门牌 / 二维码 → **换窗口，不打码**；
  - 第三人近景正脸 → 属肖像风险，**技能不预设**用不用，交使用者自己定；要用就先用逐帧确认画面里到底是谁、拍得多近；
  - 可能被读成对某个地方或某个人的指认 → 换中性空镜。
- 做法：把「这两段我拿不准」单独列出来，请用户逐段说「要 / 不要」，**不替用户拍板**，也不在索引里逐条追问。

对外发布相关的一条（建议，非禁令）：可能公开发布的成片，先问一句「外人会怎么读这个画面」，再决定用不用。

## 四、重复与对照

- **短时间**反复用同一条素材 = 看着像画面卡住，禁。
- 固定机位口播/演播室镜头重复用 = 一眼认出是同一段，禁。
- **同一地点同一机位的前后变化是叙事，不是重复**：例如同一处坡道先有高差、后来补齐，片头片尾各用一次形成对照，属于设计。
- **画面里的地面状况只做中性描述。** 碰到破损、缺失、不平这类内容，文档里只写「地面的接缝与高差」这种客观说法，不写归因、不写「证据/举证」，也不带地点指向。
- 行动镜头隔开一段时间复用、首尾呼应是允许的。
- **街景里的连锁店招、路牌一般可接受**（街拍本来就带招牌）；要避开的是「画面主体就是别人的招牌/广告」，以及可读的电话号码、门牌。

### 两种情况都可以是正解：实物变化 / 字面呼应

同一句歌词常常有两条都成立的路，候选表里两条都给，别只给一条：

- **实物变化**：歌词讲「改变」，画面给同一地点改造前后的实物对照（台阶与缓坡 → 坡道与扶手），变化看得见、可核对。注意别把「受挫」镜头错嫁在此之前——先查镜头表，别凭印象。
- **字面呼应**：画面主体本身写着歌词里的那个词（背景大屏、标题板、横幅），词在画面里是**主体**、不是角落里的小字，这时字面撞击比叙事更强。

判据：那个词要占画面的主要注意力，且不是随机背景。只是背景里恰好有个同音字，不算字面呼应。

## 五、素材索引

**标签是入口**：每条素材 2–3 个标签，只能从既有词典里选、不造新词；没标签的索引等于没有入口。

**精细度按规模自适应**（详见 `workflow.md` 第 4 步）：

| 规模 | 默认 |
|---|---|
| ≤5 条且单条 ≤10 分钟 | 直接精查 |
| ≤3 条但有 >10 分钟的长素材 | 问一句要不要精查，附预估时间 |
| 6–20 条 | 精查，开工报预估时间 |
| >20 条或总时长 >2 小时 | 建议先粗查，报预估时间并问 |

粗查与精查的差别只有一条：粗查每 5 秒一帧、只给候选区间；精查在候选区间按 1 秒抽帧，补标签与窗口。**两者都不许跳过抽帧复核。**

## 六、弃用要回写

判据只有一条：**不能用 ≠ 不好看**。

- 不好看 → 换窗口，不必写回。
- 不能用（糊、误拉近、含可读电话、肖像问题）→ **必须写回索引**，否则下一首歌还会挑到。
- 格式：整条 `⛔ 整条禁用（原因；YYYY-MM-DD）`；单窗口 `⛔ 288–292s 禁用（原因；YYYY-MM-DD）`。
- 只改索引 md，不动原片、不改其他窗口。
