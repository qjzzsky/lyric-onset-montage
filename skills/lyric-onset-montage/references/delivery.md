# 交付、改片、证据图

---

## 一、交付什么

| 件 | 必需 | 说明 |
|---|---|---|
| 成片 | ✅ | 1920×1080 / 30fps / 单轨音频 |
| 分镜首帧（拼图） | ✅ | 一格一刀，左上角编号从 **1** 起，与镜头表同号 |
| 镜头表 | 默认 | 序号 / 切点 / 时长 / 歌词 / 情绪 / 素材 / 入点 / 理由 |
| 自检报告 | 默认 | A/B、帧数差、末段电平、素材合规、改动台账 |
| 改动台.html | 默认 | 逐刀看片提改动（双通道之一），一键复制提示词贴回 |

- 客户端支持的话，**把成片和分镜图直接显示在对话面板**，让用户边看边对照，不用来回找文件。
- **边生成边落盘**：成片一出来就把分镜图与镜头表拷进交付目录；报告先落「待填」骨架。
- 内部核对用的图（包络尺子图、频谱图）**不进交付**——交付要的是一眼扫完的形式。

## 二、改片：最小改动

改片两条通道并存：口头报「秒数 + 画面」，或用 `改动台.html` 逐刀点选后复制提示词（含「时机不对」定点弹窗）。挪切点＝动两个边界：被点名刀与前一刀成对伸缩、两刀重切，素材入点与画面不动。

### 先分清用户说的是哪一种

| 用户说的 | 意思 | 做法 |
|---|---|---|
| 「第 X 秒改一下」「换这个镜头」 | 只动被点名的那部分 | 只改那几行、只重切那几刀 |
| 「重新洗一版 / 再出一版」 | 用新素材重渲**同一份分镜** | 结构不动 |
| 「结构不对 / 重新设计分镜」 | 真要重做 | 才动分镜表 |
| 「太快、没看清」「留一个」 | 常是**一条素材内部换了画面** | 切点与时长都不动，只把入点挪到要保留的那段 |

### 程度词先量化

用户的「差一点」「有点早」要先落成秒数再动手；下面这档是默认估算，动手前报一句数确认。

| 说法 | 建议位移 |
|---|---|
| 差一点 / 就一点点 | 1–3 帧（0.03–0.10 秒）|
| 有点早 | 0.10–0.20 秒 |
| 早 | 0.20–0.30 秒 |
| 太早 | 0.30–0.45 秒 |

同一刀可能连报两次，第二次按更小量级走。

### 落地五步

1. 只改分镜表里被点名的那几行（源文件 / 入点 / 说明）。
2. 只重切那几刀：跑项目里的构建脚本按 `cut:N` 重切（`templates/build_mix.py` 是全量最小版；按刀重切的 CLI 在项目里另写一层），其余 `cuts/cXX.mp4` 复用。**不要为了改一刀重跑全量。**
3. `concat` + `mux` 重出。
4. 附「只动了那一刀」的证据：改动的切片 mtime 是新的、其余未变；`nb_frames` 与总时长不变。
5. 同步镜头表与自检报告那一行。

### 改动台账

| 轮次 | 反馈 | 原来 | 现在 | 波及 |
|---|---|---|---|---|

不用刀号，用「秒数 + 画面」（如 `40.80 那刀往后两格`）；编号只能看图上实物核，不凭记忆。

对外公开案例时，台账里的反馈**只做转述，不贴原话**——用户的指令属于对话内容，不进仓库。

## 三、三类证据图，各答一个问题

| 图 | 回答 | 怎么看 |
|---|---|---|
| **双轨刀口图** | 整片切点是不是都落在字头上 | 上轨只放节拍网格，下轨只放参照点（实测字头 / 人耳切点）；只标一个数值 |
| **首帧拼图** | 每一刀的画面选得对不对 | 扫空镜 / 压人头 / 相邻两刀同素材同入点（像定格）/ 糊 / 竖屏 / 画面带烧录字幕 |
| **刀口帧对照** | 这一刀是不是真换了镜 | 左＝切点前 1 帧，右＝切点帧；内容相同＝同镜残留，整帧全黑＝黑场 |

三者不能互替：双轨图看时间、首帧图看内容、帧对照看单刀。缺一张就会出现「数字全对但画面是空镜」或「画面都对但每刀早 0.2 秒」。

**约定**：同一套图一律同名同尺寸（`cut-proof.png`，1600×900），配色与图例不变；多份案例放在一起要版式一致。

**生成方式**：数据走 `check_cut.py` / `onset_beat_probe.py`，绘图脚本 `showcase/_tools/render_cutproof.py`（PIL）。抽帧核刀口一律按帧号 `select='eq(n,N)'`，不用 `-ss`。

**图里的东西要单独审**：BV 号、作品名、门牌电话、真实歌词，文本扫描器看不见，发布前逐张看图。

## 四、交付前跑一遍

```bash
python scripts/check_cut.py --video 成片.mp4 --table 镜头表.md --expect-frames 3472 --sheet 首帧.jpg
```

输出 A/B 统计、帧数差、末段电平、每刀首帧拼图。**红了就停**，不要用「看着对」交片。
