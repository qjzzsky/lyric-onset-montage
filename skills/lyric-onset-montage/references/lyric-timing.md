# 歌词字头怎么量准

三件事分开做：**先定哪一秒算这一句的开始**（基准），**再解出偏移**（坐标轴），**最后量起音**（尺度）。
把这三件混在一起，就会得到「整片都早」或「对账全绿但听着不对」。

---

## 一、歌词文本：三个来源，单源不采信

| 来源 | 可靠性 | 怎么用 |
|---|---|---|
| 音频/视频自带的 SRT / LRC | 较可靠 | 直接给文本与句界候选；**时间轴仍不可当字头** |
| 画面的烧录字幕（MV、影视、儿童主题曲常有） | 可靠（官方）| 逐帧像素检测出段落，文本与句界都拿得到 |
| 网络歌词站 / 百科 | 低 | 只做交叉核对；会串歌、漏句、改词 |
| 语音转写（whisper 等） | 低 | **只认字，不定时间** |

**定稿条件**：至少两源一致；不一致的地方逐句听或用烧录字幕核。同一部剧/同一张专辑里的多首歌极易串源。

烧录字幕的检测参数与两个会骗人的地方见 `scripts/burned_subtitles.py` 顶部说明。
一句提醒：只改一个字的换行（同句改词）像素量几乎不变，脚本检不出，必须按 1 秒抽帧用眼睛读。

---

## 二、句界

- 句界可以听字幕、听字幕轨、听烧录字幕段——它们的**起点**是可靠先验。
- **短于 1.0 秒的条目一律并入相邻句**；字幕已经拆过半句的（中位 2–3 秒）不要重复拆。
- 括号里的内容不是旁白，判据三条：**是否与主唱同时、时长、中间有没有气口**。
  - 与主唱完全重叠 → 永不单独成刀；
  - 部分重叠 → 按主歌词字头切；
  - 独立成句且 ≥1.5 秒 → 可给一刀；<1.0 秒并入相邻句。

---

## 三、字头：从音频量，不从字幕抄

**测量口径**：300–3000Hz 带通 → 10ms RMS 包络 → 找「前 0.15 秒明显更安静、随后持续有声」的上升起点。
不要用峰值：峰值落在元音上，比辅音晚 0.1–0.3 秒。

**分层定切点**（实测：检测起音比人耳接受的位置早 0.15–0.25 秒，且修正量不恒定）：

| 情形 | 做法 | 把握 |
|---|---|---|
| 前 80ms 内有 ≥80ms 的能量谷（有气口） | 切在谷尾 +2 帧 | 几乎不会错 |
| 前一句长音压着、无气口 | 先加 +0.15 秒补偿，标 `⚠ 待确认`，交付时单独请用户听 | 只能给候选 |

**不要做的事**：

- 不要拿「一个固定阈值/系数」去追听感——同一批刀里，被判早的切点有的只爬到谷→峰的 3–9%，有的已经 90–103%，能量包络解释不了差异。
- 不要在满混音上看频谱图定字头。
- 不要把「拍网格推算字头」当主路：四首歌实测补偿后中位 61–67ms、p90 170–228ms，按 ±1 帧命中只有 6–19%。唯一能用的先验是「字头 ≈ 拍点 − 60ms」，只用于缩窗。

## 四、时间基准：先落轴，再比数

任何跨「成片 / 原曲 / LRC / 外部标尺」的比数，先跑：

```bash
python scripts/solve_audio_offset.py --video 成片.mp4 --audio 原曲.m4a
```

- 输出 `成片 0s = 原曲第几秒` 与相关系数；**r > 0.9 才认**。
- 写成表头第一行：`音轨轴 / 标尺轴 / 偏移`。不写就是等着整表漂。
- 例：某版成片 0s = 原曲 2.38 秒（成片从音乐起算）；另一版是 59.80 秒（只取了副歌）。

## 五、A / B 两个指标，不许混算

| 指标 | 公式 | 回答 |
|---|---|---|
| **A** | 切点 − 实测字头 | 刀准不准（目标 ≤ ±0.1 秒） |
| **B** | 最近网格线 − 实测字头 | 如果按鼓点切，会差多少 |

**A 的循环论证陷阱**：切点用能量法定、字头也用能量法测，两边同源；A 小只说明「切点落在能量上升沿上」，说明不了「落在人耳的字头上」。
独立验收只有两条路：**外部已验证版本当标尺**，或**请用户人工定位 2 句**。两条都断，就如实说「没有独立标尺」。

**B 的前提是网格可信**：

- 测速用**全带谱通量**自相关（限 60–120 BPM），低频包络会掉八度坑（84.5 被量成 96 或 167）；
- 相位拟合只用 40–160Hz 低频包络；相位集中度 R < 0.3 时，B 只能报量级，不能报单点中位数；
- 测速必须做抛物线亚采样插值，否则长曲子上网格整段漂。

**报告格式**：n / 中位 / 最大，三件套缺一不算报告；观测点全篇统一（「能量峰」还是「上升起点」，不能一边写一个）。

## 六、三角互证（交付前）

把同一句的三个数分开登记：

| 句号 | 文本 | 字幕起点 | 能量起音 | 词级时间戳 | 差值 | 置信度 |
|---|---|---|---|---|---|---|

- 差 >0.2 秒的句子 → 单独列出来请用户听，不自行定稿。
- 三源两两吻合到帧级也**排除不了共享同一错误源**（都可能从同一份字幕派生）。
- 用户报「每句开头都早了」时，排查顺序：① 计划切点 → ② 解码成片实测换镜帧 → ③ 原曲音轨起音。三者两两吻合 = 不是合成错位，问题在计划切点的来源；先怀疑 ffmpeg 就会白重跑拼接。
