# 歌词字头混剪 · Lyric-Onset Montage

一首歌 + 一个素材目录 → 一版每一刀都落在歌词首字上的混剪。
核心三件事：**切点贴实测字头**、**选画面与定时间分开判**、**改片只动被点名的那一刀**。

## 前置红线（动手前先过这 5 条）

1. **切点只认实测字头，不认 LRC / SRT 行时间。** 字幕普遍比歌声早 0.1–0.27 秒（案例实测 0.17–0.27 秒，中位约 0.24 秒）；用字幕时间下刀，整片都早。
2. **结尾**：止点落在字头前 0.3–0.4 秒，淡出 2.5–3 秒，成片末 0.1 秒电平 < −45 dB。淡出起点同时是最后一刀的画面切点。
3. **素材窗口必须抽帧定案。** 清单或索引里写的窗口会错（实测 18 个镜头里 5 处描述与画面对不上）。
4. **不能用就打码当解决方案。** 电话牌、车牌、二维码、发糊素材：换窗口，不后期涂抹。
5. **帧精确切片、拼完核帧数、合曲不用 `-shortest`。** 三条都会静默出错：吃帧、截尾、取整成同一帧。

## 硬规则

1. **切点 = 该句第一个字发音的瞬间，±0.1 秒。** 「早了」比「晚了」刺耳得多。
2. **一句最多两刀；单刀 ≥1.5 秒（副歌最密 1.2 秒）；整首 60–90 刀。** 短于 1.0 秒的字幕条目一律并入相邻句。
3. **时间轴连续无缝**：每刀延到下一刀起点，最后一刀收到截点，首刀从 0 秒铺满——前奏长到十几秒也要按空镜/环境/行动镜排 2–4 刀，不留给黑场。
4. **帧精确**：`N[i] = round(t*30)`，每刀 `-frames:v FR[i]`，不用 `-t`。下刀前逐刀验「入点 + 该刀时长 ≤ 源片时长 − 1/30」。
5. **拼完核 `nb_frames`**；`-c copy` 拼接可能丢帧，少了就整段重编码兜底。
6. **合曲用单轨 + 显式 `-t {总时长}`**，禁用 `-shortest`；用原始音频（48k 立体声），不用分析用的 16k 单声道。
7. **竖屏进横版垫模糊底**，不留黑边、不硬裁。压暗后量两侧各 300px 的均值：15–110 才算「垫底在、又不抢主体」，接近 0 就是压过头。
8. **不用静止照片充镜头。** 同一条素材隔 3 秒两帧完全一样 = 照片。
9. **分镜编号从 1 起，图上与表上同号。** 报改动用「秒数 + 画面」，不报刀号。
10. **改片 = 最小改动。** 只改被点名的行、只重切那几刀，其余切片复用；交付附「其余没动」的证据。
11. **候选不是单方案。** 每段 3–4 首选 + 3–6 备选，返工只换素材、不动时间轴。
12. **交付边生成边落盘**：成片一出来就把分镜首帧、镜头表拷进交付目录；运行被截断时手上至少是成套的。

## 可调开关（默认开，一句指令就改）

| 开关 | 默认 | 怎么改 |
|---|---|---|
| **情绪对位** | 同向：消极/吃力句配「受阻、用力」，积极/光句配「走得通、被接住」 | 「这句别配这么沉的画面」/「对位关掉，只按事件贴合」 |
| **出镜与语境核对** | 画面里有人、有牌、有可读文字时问一句，并给替代镜头 | 「这个人不能出镜」→ 换镜头；「不用问，按现状剪」→ 关掉询问 |
| **镜头密度** | 单刀 ≥1.5 秒，整首 60–90 刀 | 「再碎一点」/「留长一点」 |
| **范围与结尾点** | 整首；半首/切片按说的来 | 开工时说清，定了不中途改 |
| **进度播报** | 每个阶段报一次 | 「别报」/「每五分钟一次」 |

开关只影响取舍，不影响硬规则：切点依然贴字头。

```text

范围：<整首 / 到第一遍副歌 / 某句为止>
```

## 字头怎么量（权重与分层）

- **歌词文本**：自带 SRT/LRC → 画面烧录字幕 → 网络歌词站交叉核对。**单源不采信**，歌词站会串歌、漏句、改词。
- **句界**：可用字幕/字幕轨/烧录字幕时间定句界；短于 1.0 秒的条目并句。
- **字头**：300–3000Hz 带通 + 10ms RMS 包络，找「前 0.15 秒明显更安静、随后持续有声」的上升起点。
  - **有气口**（前 80ms 内有 ≥80ms 能量谷）→ 谷尾 +2 帧，直接定。
  - **无气口的连唱句** → 加 +0.15 秒补偿并标 `⚠ 待确认`，交付时单独圈出来请用户听。
- **辅助校验**：谱通量、拍网格、词级时间戳只用于缩窗和对照，**不出终值**。
- **时间基准**：跨「成片 / 原曲 / LRC / 外部标尺」比数之前，先解出「成片 0s = 原曲第几秒」（10ms 包络互相关，r>0.9 才认）。

## 怎么证明切得准（A / B 两个指标，不许混算）

| 指标 | 公式 | 回答 |
|---|---|---|
| **A** | 切点 − 实测字头 | 刀准不准 |
| **B** | 最近网格线 − 实测字头 | 按鼓点切会差多少 |

- **验证基准不能与切点同源**：切点用能量法定、字头也用能量法测 = 自证。破循环只有两条路：外部已验证版本当标尺，或请用户人工定位 2 句。
- 切点一动，逐刀 A 跟着动，**不要拿单刀 A 的差值倒推「该挪多少」**。
- 报数一律给 **n / 中位 / 最大** 三件套。
- 收片前跑 `scripts/check_cut.py`：A/B、帧数差、末段电平、首帧拼图一次出。**脚本红了就停**，不要用「看着对」交片。

## 改片（交付后修改）

- 「改第 X 秒那一处」「换这个镜头」→ 只改那几行、只重切那几刀（`cut:N`）。
- 「重新洗一版 / 再出一版」→ 用同一份分镜重新渲染，不动结构。
- 「结构不对 / 重新设计分镜」→ 才真的重做。
- 「太快、没看清」→ 先抽首/中/末帧：若是一条素材内部换了画面，切点与时长都不动，只把入点挪到要保留的那段。
- 程度词先量化再动手：默认「差一点」≈ 1–3 帧、「有点早」≈ 0.10–0.20 秒、「太早」≈ 0.30–0.45 秒；拿不准就报一个数等点头。
- 改完把「原来 → 现在 → 你的话」写进自检报告，并同步镜头表那一行。

## 边界

- **不下载、不爬取任何音乐或视频**；文件由用户提供，版权与责任在用户。
- 拿不准的素材**问一句**再下刀，不默认可用。
- 只处理用户提供的素材与指令；不替用户判断内容该不该公开。
