# 交付形态 · 人和模型怎么一来一回（优化版）

> 这份写的是「接口」，不是「技术参数」。返工轮次最多的原因不是切不准，
> 是**说的和改的不是同一刀**。这一版把接口定死在改动台里，后面照抄。

## 一、交付五件套，不多不少

| 文件         | 作用                        | 受众      |
| ---------- | ------------------------- | ------- |
| `成片.mp4`   | 唯一成品                      | 你       |
| `分镜首帧.jpg` | 一格一镜，一眼扫完，用来点名哪刀不对        | 你       |
| `镜头表.md`   | 每刀：切点 / 时长 / 歌词 / 素材 / 入点 | 我 + 你核对 |
| `自检报告.md`  | 机器体检数字 + 改动台账 + 还能改什么     | 你       |
| `改动台.html` | 逐刀看片提改动，一键复制提示词贴回 AI      | 你       |

**不进交付的东西**：包络尺子图、频谱图、中间切片、切片日志。这类图只用来核对，看的人只会觉得烦。

## 二、报刀：改动台优先，口头照旧

**改动台**：点分镜 → 从切点前 3 秒播起 → 给那一刀选「无需调整 / 时机不对 / 换素材 / 我有别的想法」→ 点汇总按钮复制提示词贴回 AI。

- **时机不对**：弹窗循环播「切点前 3 秒～刀后 3 秒」，看到该切的位置点「调整到这里」，目标切点直接写进提示词，不试数字。
- **键盘**：← → 快退/快进 2 秒，空格暂停，全局和弹窗都管。
- **列表自动跟随**：播放到哪刀，列表跟到哪刀，不选行也不会记错刀。
- **汇总按钮两态**：没标改动＝绿色「复制确认提示词」（确认无误、可直接生成）；标了改动＝蓝色「复制改动提示词」。
- **双语界面**：右上角「中 / EN」开关随时切换（初始语言跟着使用者提示词的语言走），提示词文案随界面语言。

**口头**：用「秒数 + 画面」，不用编号——「40.80 那刀往后两格」对，「第十二刀早」错。秒数取镜头表里的切点，画面说歌词或画面内容。

## 三、编号差 1 的血案（真实发生）

当年那份交付里有两套编号：`镜头表.md` 的 `#1`–`#16` 与 `分镜首帧.jpg` 图注的 `#00`–`#15`（**整体差 1**）。用户看图报号、模型按表号去改 → 整体错一刀，白出一版。

之后的规矩：

1. 图注和表号**必须同号**（现版拼图 `#01`–`#16`，与镜头表一致）；
2. 两套号并存时，一律先按**画面内容**确认，再动手；
3. 用户报号时优先认「秒数 + 画面」，编号只作辅助。

## 四、程度词 → 位移量（默认估算，动手前报数）

| 说法       | 默认挪               |
| -------- | ----------------- |
| 一点点（早/晚） | 1–3 帧（0.03–0.10s） |
| 有点早      | 0.10–0.20s        |
| 早        | 0.20–0.30s        |
| 太早       | 0.30–0.45s        |

同一刀连报两次时（「早」→挪→「还一点点早」），第二次必须按更小量级走。一律按 0.3 秒挪会来回过冲。**口头调 1~2 次还不准 → 转改动台「时机不对」定点。**

## 五、竖屏垫底：参数是「加减」，不是「比例」

```bash
split=2[bg][fg];
[bg]scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,
    gblur=sigma=60,eq=brightness=-0.10:saturation=0.75:contrast=0.95[bg2];
[fg]scale=1920:1080:force_original_aspect_ratio=decrease[fg2];
[bg2][fg2]overlay=(W-w)/2:(H-h)/2
```

**坑**：`eq=brightness` 是**整体加减亮度级**，不是按比例。写 `-0.45` 等于全画面减约 115 级，暗部直接削到 0——看着就是黑边。

判据：成片抽一帧，左右各取 300px 求均值。

- **15–110** = 模糊底在，且不抢主体
- **≈0** = 已被压成黑边，回去改参数

## 六、可微调清单（你一句话，我改一处）

| 用户会怎么说        | 改什么                             | 波及           |
| ------------- | ------------------------------- | ------------ |
| 「这句换一个」       | 换该刀素材，切点不动                      | 1 刀          |
| 「这句切早了/晚了」    | 挪这一刀（改动台定点最准）                   | 1 刀 + 前后两刀时长 |
| 「这句想再碎一点」     | 气口补一刀                           | +1 刀，总帧数重算   |
| 「这个镜头糊 / 压人头」 | 换窗口或换素材                         | 1 刀          |
| 「两个画面太快」      | 先查是不是一条素材内部换画面；是则挪入点，不是才并刀      | 1 刀          |
| 「结尾收干净点」      | 止点前移 + 淡出加长                     | 尾段 + 总帧数全变   |
| 「竖版底板太亮/太暗」   | 调 brightness（保持在 −0.05 ~ −0.15） | 竖屏刀          |
| 「整片每句都早」      | 走标尺对账 / 三步法，只挪句首刀               | 多刀，素材顺序不动    |

## 七、每次改完必须回三样

1. **原来 → 现在 → 反馈**（写进自检报告的改动表，下一轮拿它对账）
2. **影响范围**：动了几刀、其余刀是否复用（切片 mtime 不变可证）；挪切点 = 动两个边界（被点名刀与前一刀成对伸缩）
3. **重核两个数**：`nb_frames` 与改前一致、末尾 0.1s 仍 < −45dB；多刀挪切点附**切点实测表**（`scripts/cut_switch_probe.py` 帧差扫描）
