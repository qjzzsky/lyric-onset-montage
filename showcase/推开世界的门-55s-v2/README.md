# 案例：《推开世界的门》55 秒切片 · 优化版（改动台）

**曲目**：《推开世界的门》｜演唱 杨乃文｜词曲 火星电台 / 黄少峰

> 与 `../推开世界的门-55s/` 是同一支片子的两版，**并存不删**：旧版是「一次做对 + 六轮口头改片」的样本；
> 这一版回答的是——**加上改动台之后，改片可以做到什么程度**。

## 一句话

从一首 281 秒的歌里只取 55 秒（原曲 59.80 → 114.80s），16 刀，每刀 ≥ 2.6 秒；
7 刀经改动台「时机不对」弹窗人耳定点后重切，实测换镜帧全部命中（偏差 ≤ 0.02s），总帧数 1650 不变。
**人耳定点的刀以耳朵为准**，机器口径只作对照（A 切点−谱通量峰 绝对中位 81ms / B 切点−网格 绝对中位 220ms，15 个字头刀）。

## 这一版补的是什么

| 旧版没有的东西                                  | 为什么值钱                                                        |
| ----------------------------------------- | ------------------------------------------------------------ |
| **改动台「时机不对」定点**：循环播「切点前 3 秒～刀后 3 秒」，看到该切的位置点「调整到这里」，目标切点直接写进提示词 | 使用者不用报「早了/晚了」试数字，耳朵说了算；两批 7 刀全部一次定点成功 |
| **最小改动重切**：只重切被点名的刀，相邻刀跟着伸缩，素材入点与画面不动 | 4 刀定点实际只动 8 个边界切片，其余复用；总帧数不变 |
| **帧级实测对账**：`scripts/cut_switch_probe.py` 帧差扫描换镜帧 | 7 刀换镜帧实测与规格偏差 ≤ 0.02s，重切不再是「应该没问题」 |
| **断句依据不许猜**：半句格子可回溯到生产记录（spec.json + 词级转写 + 能量峰）| 旧版半句按语义猜错两三个字，改动台全对不上；证据链断了先查生产目录 |
| **汇总两态按钮**：无改动＝绿色「复制确认提示词」（确认无误、可直接生成），有改动＝蓝色「复制改动提示词」 | 绿=定稿放行、蓝=带改动返工，不用问就知道这轮是过还是改 |

## 改动台：改片的两条通道（并存）

1. **口头/对话**：照旧，「第 X 秒」「几分几秒」直接说。
2. **`改动台.html`**（五件套之一，单文件、不联网）：点分镜从切点前 3 秒播起；键盘 ← → 快进快退 2 秒、空格暂停；列表 LRC 式自动跟随播放位置；「时机不对」弹窗定点；四个状态按钮（无需调整 / 时机不对 / 换素材 / 我有别的想法）；最后两态按钮复制提示词贴回 AI。

## 素材排除四条（沿用旧版）

1. **历史纪念地 / 战争记忆**：按使用者要求不选。
2. **路面的不整与高差**：按使用者要求不选。
3. **可读的电话、门牌、车牌**：不打码，直接换窗口。
4. **使用者自定的排除项**：由用的人自己定，不是技能规则。

## 下一步（未验证，别当结论）

「节拍网格缩窗 + 窗内谱形精定位」的独立论证结论是网格给不了帧级落点，只值「半拍 + 60ms」的先验。
**这份案例里的字头定位 = 词级转写定「哪个字」+ 能量峰定「字头毫秒」+ 人耳收口，不要写成「网格推算」。**
