# 工作流（一页）

| # | 步骤 | 输入 → 输出 | 失败长什么样 |
|---|---|---|---|
| 1 | LRC 对齐 | 音轨 + 专辑版行级 LRC → 每句候选窗 | 偏移算错：整片时长对不上，句句错位 |
| 2 | 偏移解算 | ≥2 句锚点 → 偏移（本例 **+1.83s**）+ 相关系数 | 相关度 <0.9 = 不是同一母带，算下去全错 |
| 3 | 字头定位 | 候选窗（±0.45s）→ 能量上升起点 | 抓到鼓点/和声：切点落在鼓上，听感「抢拍」 |
| 4 | 候选表 | 索引 → 3–4 首选 + 3–6 备选 | 只给单方案：一句不对整片重排 |
| 5 | 预览审批 | 候选表 → 540p 预览 + 每刀首帧拼图 | 不预览：下刀才发现糊素材/电话牌/压人头 |
| 6 | 帧精确下刀 | 定稿时间轴 → 成片 | `-t` 累计漂移；`-c copy` 拼接丢帧（154→151） |

**一条主线**：字头只认实测，不认 LRC 行时间——本例 LRC 说 118.54s、实测 118.44s，差 0.1s 就够让结尾漏进半个字。
