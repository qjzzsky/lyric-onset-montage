# 案例②：《骄傲的少年》半首（115.7 秒 / 33 刀）

**曲目**：《骄傲的少年》｜演唱 南征北战NZBZ｜词 赵辰龙｜曲 汀洋

> 这是技能从「能剪」走到「有基准」的一版：把 LRC 的行时间靠互相关钉到音轨上，
> 再用实测字头下刀。A / B 两个指标也是在这一版分成两个数的。

## 一句话

115.733 秒、3472 帧、33 刀；专辑版行级 LRC 与音轨的偏移解出来是 **+1.83 秒**，
20 句复核中位误差 **0.10 秒**。按拍切实测差 **中位 222 毫秒、最大 346 毫秒**（n=20，半拍 357 毫秒）。

## 规格（实测）

| 项 | 值 |
|---|---|
| 成片 | 1920×1080 / 30fps / **3472 帧 = 115.733 秒** / AAC 48k 立体声 |
| 刀数 | 33（最短 1.5 秒级，最长约 5 秒） |
| 时间基准 | 成片 0s = 原曲 **2.38 秒**（原曲开头是数字静音，成片从音乐起算） |
| LRC 偏移 | **+1.83 秒**；20 句复核中位误差 0.10 秒 |
| 贴拍对照（B） | 中位 **222ms**、四分位 186–315ms、最大 **346ms**（n=20）；曲速 84.0 BPM，半拍 ≈ 357ms |
| 末尾电平 | 末 0.1 秒 **−47.3 dBFS**（止点离字头 0.34 秒 + 2.6 秒淡出） |
| 返修 | v1 → v2，三项：糊素材整条弃用、含电话的窗口弃用、结尾余量加长 |

## 这一版补了什么

| 前一份没有的 | 为什么值钱 |
|---|---|
| **把时间基准解出来** | 有 LRC 但没有可信偏移时，整表会漂；互相关（r>0.9）一次解决 |
| **A / B 分开算** | 之前把「切点−字头」和「格线−字头」混着说，会得出「贴拍只差 80ms」这种自相矛盾的数 |
| **弃用要回写索引** | 两处「不能用」（画面糊、牌面含电话）写进索引，下一首歌才不会再挑到 |
| **交付包定型** | 成片 / 分镜首帧 / 镜头表 / 自检报告，边生成边落盘 |

## 刀 13–16：三句歌词底下的四刀

![四刀的分镜条](sequence.png)

| 刀 | 成片时间 | 歌词 | 画面 | 源片 |
|---|---|---|---|---|
| 13 | 45.833 | 转眼间 | 台阶与缓坡同框（变化的最小单位） | `20260220_192815_662` @10s |
| 14 | 48.667 | 一切都已改变 | 坡道与扶手同框（改造后的日常） | `20260501_132228_874` @3s |
| 15 | 51.167 | 新的起点 新的世界就在眼前 | 车门打开、司机弯腰拉出蓝色踏板，到踏板落地铺平 | `20260626_224601_043` @410s |
| 16 | 54.167 | 新的起点 新的世界就在眼前 | 站台抵达，从火车上下来 | `20260626_224601_043` @5s |

转折不靠旁白：四刀各自都有实物可指（台阶 → 坡道 → 车上的坡道）。第 14 刀比第 13 刀多出来的那道**扶手**，就是「一切都已改变」最直白的证据——不是抽象的变好，是多了可以扶的东西。

「新的起点」占了两刀：第 15 刀是一个连续的长镜头，从车门打开、司机弯腰拉踏板开始，到踏板铺平结束，中间没有换镜；第 16 刀接着换到站台。

## 这一版仍不完美

- A 的漂亮数字有循环论证成分（切点用能量法定、字头也用能量法测），独立验收靠人耳。
- 开头 2.38 秒是数字静音，不剪掉会得到 2.4 秒无声画面。
- 首版合曲误用了分析用的 16k 单声道 wav，出片后才发现，换原始 m4a 重做。
