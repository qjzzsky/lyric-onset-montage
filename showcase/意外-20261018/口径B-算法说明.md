# 「字头 vs 鼓点网格」口径 B · 完整算法

> 目的：证明「切点贴字头」比「切点贴鼓点」准。两个指标必须分开算，混在一起就会算出「贴拍只差 80ms」这种自相矛盾的数。

## 0. 两个指标，别混

| 指标 | 公式 | 回答什么问题 |
|---|---|---|
| **A 刀准不准** | `A = 切点时间 − 字头实测时间` | 我这一刀切在字头上了吗 |
| **B 贴拍会差多少** | `B = 最近网格线时间 − 字头实测时间` | 如果按鼓点切，会偏多少 |

**红线**：算 B 时绝不能用「切点时间」去找最近网格线——那是循环论证（切点本来是照字头定的），会得出一个假的小偏差。

## 1. 取音频

```bash
ffmpeg -y -v error -i "原曲.mp3" -vn -ac 1 -ar 22050 song.wav
```

整首解出来，**不要只截窗口**：窗口只用于画图，检测要在全曲上做（边界效应会让首尾几句的起音检测失真）。

## 2. 字头（onset）检测 —— 能量法

```python
hop, win = 128, 1024          # 5.8ms / 46ms，22.05kHz
S = |rfft(帧 × hann)|
flux = max(0, diff(S, axis=0)).sum(axis=1)
flux /= flux.max()            # 归一化
peaks = find_peaks(flux, height=0.06, distance=int(0.16*sr/hop))
```

- 每句字头：在**预期位置 ±0.35s** 内取 flux 最大值那一帧；**找不到就标「未测」**，不许估、不许插值。
- 可选提纯：先 300–3000Hz 带通再算 RMS 上升（人声频段，抗鼓点干扰更好）。
- **不要用 whisper 的词级时间当字头**：中文唱词上它会漂到 1 秒以上（本例「不」字漂了 1.5s，还吐出「作词作曲」）。whisper 只用来给句子贴歌词，不用来定时间。

## 3. 拍网格 —— 必须先定相位

```python
bpm = 自相关(flux, 范围 55–180 BPM)      # 只给间隔，不给起点
period = 60 / bpm
phase = argmax_{ph ∈ [0, period)} Σ flux(ph + k·period)   # 步长 10ms 扫
grid = [ph + k·period for k …]
```

**关键**：BPM 只决定格子多宽，**不决定哪一下开始一句**。相位找错，B 就整体失真。所以一定要做相位扫描，别用固定 4/4 对齐。

## 4. 算数

```
对每一句 i：
  A_i = cut_i − onset_i
  B_i = nearest(grid, onset_i) − onset_i      ← 用 onset 找最近格子
统计：median(|A|), max(|A|), median(|B|), max(|B|)，n = 句数
```

- 前奏刀（没有歌词的那几刀）**排除**，并在文里写明排除了哪几刀、为什么。
- 报「半拍」做参照：`half_beat = 30 / BPM`（本例 80.1 BPM → 375ms）。

## 5. 四项自检（做完再发结论）

1. **相位自检**：把每个 onset 到最近格子的距离 ÷ 格距，做直方图。应当铺在 0–0.5 之间；**如果全挤在 0 附近，说明网格被吸到人声上了，结论作废**。
2. **数量级自检**：`median(|B|)` 若小于 `half_beat/5`（本例 <75ms），几乎一定是算错或只挑了准的句子——按拍切不可能这么准。
3. **抽样复核**：随机抽 3 句，把声谱图放大到 ±100ms，人工确认字头位置在 ±50ms 内。
4. **一致性自检**：A 和 B 不应同号同值；若完全一样，说明把切点当成字头用了。

