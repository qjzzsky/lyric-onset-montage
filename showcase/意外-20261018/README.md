# 案例①：《意外》混剪（17 刀 / 80.1 BPM）

**曲目**：《意外》｜演唱 薛之谦｜词曲 杨子朴

> 开始的地方。当时先按「一句一刀」切，用户一句「要等那个『不』字的瞬间」，
> 才把切点从句子改成字头。技能里「切点贴字头」这条，就是从这一版长出来的。

## 一句话

17 个歌词刀，切点与实测字头的中位差 **60 毫秒**；同一批刀如果改成「贴最近鼓点」，
中位差 **160 毫秒**、最大 **369 毫秒**——半拍都不到，耳朵一听就是抢拍。

## 规格（实测）

| 项 | 值 |
|---|---|
| 刀数 | 17（去掉 0.00 / 6.10 两个前奏刀）|
| 曲速 | 80.1 BPM，格距 ≈ 0.75 秒，半拍 ≈ 375 毫秒 |
| 切点口径 | 每句第一个字的发音瞬间 |
| A（切点 − 实测字头） | 中位 **60ms** |
| B（最近鼓点 − 实测字头） | 中位 **160ms**、最大 **369ms** |
| 交付 | 断句版（纯音乐轨）+ 穿插版（保留原声对话）|

## 这一版踩出来的三件事

1. **字头只认实测。** 这一版「不」字实测 46.93 秒，前一版切在 46.0 秒——差 0.9 秒，用户第一句就听出来了。
2. **候选表不是摆设。** 每句只有一个选择时，返工就是整片重排；这一版之后改成每段 3–4 首选 + 3–6 备选。
3. **双版本交付，改一处等于改两版。** 穿插版复用断句版的镜头，素材或切点一改，两版都要重出。
