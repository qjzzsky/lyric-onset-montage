# 案例：《推开世界的门》55 秒切片

**曲目**：《推开世界的门》｜演唱 杨乃文｜词曲 火星电台 / 黄少峰

> 第三份案例。前两份回答「一次做对」和「没有 LRC 也能做」，这一份回答另外两件事：
> **只剪一段副歌怎么切**，以及**交付跟用户来回改的时候，接口该怎么设计**。

## 一句话

从一首 281 秒的歌里只取 55 秒（原曲 59.80 → 114.80s），16 刀，每刀 ≥ 2.6 秒；
字头刀与实测起音的**绝对中位差 35ms**（谱通量口径，带符号中位 +2ms），按 70 BPM 鼓点切会差 **214ms**。

## 规格（实测）

| 项 | 值 |
|---|---|
| 成片 | 1920×1080 / 30fps / **55.000s / 1650 帧** / H.264 + AAC 192k 48kHz |
| 刀数 | 16 刀（最短 2.60s，最长 4.30s） |
| 音频区间 | 原曲 59.80 → 114.80s（成片 0s = 原曲 59.80s） |
| 淡出 | 52.0s 起淡 3.0s，落在「自负的胆量」唱完后的器乐过门里 |
| 末尾电平 | 末 0.1 秒 **−57.8 dBFS** |
| 音量 | mean −14.5 dB（母带 −14.3 dB），没做二次压缩 |
| 字头对齐 | A 谱通量口径 **中位 +2ms / 绝对中位 35ms**（最大 130ms）；RMS 上升起点口径 **中位 −17ms / 绝对中位 107ms**（最大 457ms）；n = 10 个字头刀。**两个口径差 0.1s 不是矛盾**：谱通量峰落在元音上，RMS 上升起点在辅音前，同一条红线被两把尺子量 |
| 贴拍对照 | B（最近鼓点−字头）**中位 214ms**；曲速 70.0 BPM，格距 0.857s |

## 这份案例补的是什么

| 前两份没有的东西 | 为什么值钱 |
|---|---|
| **短切片结构**：只取副歌一段，无前奏、无长间奏 | 前两份都是半首（115.7s / 98s），含 40% 以上无词段；这份是「从头到尾都有词」，切点密度和情绪走向完全不同 |
| **交付接口定型**：成片 + 分镜首帧 + 镜头表 + 自检报告，四件，不多不少 | 尺子图/频谱图确认不进交付——它只用来核对，不进给人看的包 |
| **改片全过程**：六轮、9 处实改，每处都记了「原话 → 原来 → 现在」 | 这是「已交付后怎么改」最完整的一份样本，比前两份加起来都细 |
| **能量法的天花板**：机器测着对、耳朵听着早 | 见 `../` 的案例与本目录自检报告；结论是能量法只能出候选，不能出终值 |

## 六轮改动（真事，用来校准「改片」的手感）

> 计数口径：第 1 轮改错编号、已全部还原；第 3 轮是参数微调；真正落在刀口与素材上的是第 2、4、5、6 轮，共 9 处。

| 轮次 | 你说 | 改了什么 | 波及 |
|---|---|---|---|
| 1 | 报「六刀偏早」（按图注号报的） | 误按镜头表编号改，**改错 4 刀** | 白出一版，4 刀还原 |
| 2 | 同一批刀重报（这次按画面认） | 按画面重认，6 刀各后移 0.25–0.70s | 6 刀 + 相邻时长 |
| 3 | 竖版素材缺底板模糊 | `eq=brightness` 从 −0.45 改 −0.10（−0.45 是整体减亮，暗部被削成 0，看着像黑边） | 3 个竖屏刀 |
| 4 | 十二刀再挪 0.10 秒 | 40.70 → 40.80（3 帧） | 1 刀 + 邻刀 |
| 5 | 两个镜头切得太快 | 不是两刀，是同一条素材 1:27 人群特写摇到 1:29 奶龙；改入点，用奶龙填满原 3.8s | 1 刀，切点不动 |
| 6 | 换掉一组容易引起联想的画面 | 地面状况那组 → 看台环廊；同时定下四条排除规则 | 1 刀 |

## 素材排除四条（从这一轮定下来的）

1. **历史纪念地 / 战争记忆**：不碰（桥面素材这类）。
2. **路面的不整与高差**：不碰——街拍里这类画面太容易被读成对某地的指认，换成中性画面更省事。
3. **可读的电话、门牌、车牌**：不打码，直接换窗口。
4. **使用者自定的排除项**：第三人近景正脸这一类，是这一版作者自己的风险偏好，不是技能规则——换不换，由用的人自己定。
