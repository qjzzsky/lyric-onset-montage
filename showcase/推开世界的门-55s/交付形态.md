# 交付形态 · 人和模型怎么一来一回

> 这份写的是「接口」，不是「技术参数」。三个作品里，返工轮次最多的原因不是切不准，  
> 是**说的和改的不是同一刀**。这一版把接口定死了，后面照抄。

## 一、交付就四件，不多不少

| 文件         | 作用                             | 受众      |
| ---------- | ------------------------------ | ------- |
| `成片.mp4`   | 唯一成品                           | 你       |
| `分镜首帧.jpg` | 一格一镜，一眼扫完，用来点名哪刀不对             | 你       |
| `镜头表.md`   | 每刀：切点 / 时长 / 歌词 / 偏差 / 素材 / 入点 | 我 + 你核对 |
| `自检报告.md`  | 机器体检数字 + 改动台账 + 还能改什么          | 你       |

**不进交付的东西**：包络尺子图、频谱图、中间切片、切片日志。这类图只用来核对，看的人只会觉得烦。

## 二、报刀：用「秒数 + 画面」，不用编号

**正确**：「40.80 那刀往后两格」（秒数 + 一句记得住的画面）  
**错误**：「第十二刀早」

原因见下一节。秒数取镜头表里的切点（成片时间），画面说歌词或画面内容，任选其一你记得住的。

## 三、编号差 1 的血案（真实发生）

当年那份交付里有两套编号：

- `镜头表.md`：`#1`–`#16`，`#1` = 0.00s
- `分镜首帧.jpg` 图注：`#00`–`#15`，`#00` = 0.00s —— **整体比表小 1**（现版拼图已重出，图注 `#01`–`#16`，与表同号）

用户看的是图，口头报的自然是图注号。模型按表号去改 → **整体错一刀**：他说 6 刀，模型改到了 6 个位置，其中 4 个是他没提的（检票口、复兴号、漫展、广场），白出一版，再花一轮还原。

之后的规矩：

1. 图注和表号**必须同号**（新脚本已统一成 `#01` 起，与镜头表一致）；
2. 老交付里两套号并存时，一律先按**画面内容**确认，再动手；
3. 用户报号时优先认「秒数 + 画面」，编号只作辅助。

## 四、程度词 → 位移量（默认估算，动手前报数）

| 说法       | 默认挪               |
| -------- | ----------------- |
| 一点点（早/晚） | 1–3 帧（0.03–0.10s） |
| 有点早      | 0.10–0.20s        |
| 早        | 0.20–0.30s        |
| 太早       | 0.30–0.45s        |

同一刀连报两次时（「早」→挪→「还一点点早」），第二次必须按更小量级走。一律按 0.3 秒挪会来回过冲。

## 五、竖屏垫底：参数是「加减」，不是「比例」

```bash
split=2[bg][fg];
[bg]scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,
    gblur=sigma=60,eq=brightness=-0.10:saturation=0.75:contrast=0.95[bg2];
[fg]scale=1920:1080:force_original_aspect_ratio=decrease[fg2];
[bg2][fg2]overlay=(W-w)/2:(H-h)/2
```

**坑**：`eq=brightness` 是**整体加减亮度级**，不是按比例。写 `-0.45` 等于全画面减约 115 级，暗部直接削到 0——实测两侧亮度 0.0，看着就是黑边，用户会说「没有底板模糊」。

判据：成片抽一帧，左右各取 300px 求均值。

- **15–110** = 模糊底在，且不抢主体
- **≈0** = 已被压成黑边，回去改参数

## 六、可微调清单（你一句话，我改一处）

| 用户会怎么说      | 改什么                             | 波及           |
| ------------- | ------------------------------- | ------------ |
| 「这句换一个」       | 换该刀素材，切点不动                      | 1 刀          |
| 「这句切早了/晚了」    | 挪这一刀，按上表量级                      | 1 刀 + 前后两刀时长 |
| 「这句想再碎一点」     | 气口补一刀                           | +1 刀，总帧数重算   |
| 「这个镜头糊 / 压人头」 | 换窗口或换素材                         | 1 刀          |
| 「两个画面太快」      | 先查是不是一条素材内部换画面；是则挪入点，不是才并刀      | 1 刀          |
| 「结尾收干净点」      | 止点前移 + 淡出加长                     | 尾段 + 总帧数全变   |
| 「竖版底板太亮/太暗」   | 调 brightness（保持在 −0.05 ~ −0.15） | 竖屏刀          |
| 「整片每句都早」      | 走标尺对账 / 三步法，只挪句首刀               | 多刀，素材顺序不动    |

## 七、每次改完必须回三样

1. **原来 → 现在 → 反馈原话**（写进自检报告的改动表，下一轮拿它对账）
2. **影响范围**：动了几刀、其余刀是否复用（切片 mtime 不变可证）
3. **重核两个数**：`nb_frames` 与改前一致、末尾 0.1s 仍 < −45dB
