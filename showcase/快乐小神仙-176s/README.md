# 案例：《快乐小神仙》整首（176 秒 / 47 刀）

**曲目**：《快乐小神仙》｜演唱 天唱组合｜词 张藜｜曲 肖白

> 第四份案例，也是**四份里唯一一份 0 返修的**：交付后复听，没有要求挪动任何一刀。
> 前面三份都在回答「怎么把刀对准」，这一份回答另一个问题：**没有字幕轨、没有 LRC，只有烧在画面里的字幕，能不能一遍做准。**

## 一句话

176.00 秒 / 5280 帧 / 47 刀，歌词来自官方 MV 的**烧录字幕**（像素检测出 37 条字幕段），
刀口全部由音轨能量实测落定。交付后复听，同样没有要求再挪。

## 规格（实测）

| 项 | 值 |
|---|---|
| 成片 | 1920×1080 / 30fps / **176.00s / 5280 帧**（差 0 帧）/ AAC 256k 44.1k 立体声 |
| 刀数 | 47（最短 2.39s，最长 5.27s，16 刀/分） |
| 曲速 | 110.9 BPM（格距 0.541s） |
| 句界来源 | 官方 MV **烧录字幕**，逐帧像素检测，37 段，边界精确到 1 帧 |
| 字头 | 300–3000Hz 带通 + 10ms RMS 包络；有气口 → 谷尾 +2 帧；连唱句 → +0.15s 并标待确认 |
| **A**（切点−字头） | 中位 **+5ms** / 绝对中位 **35ms** / 最大 291ms（n = 29 个字头刀） |
| **B**（按鼓点切会差多少） | 绝对中位 **169ms** |
| 末尾电平 | 末 0.1s **−84.8 dBFS** |
| 返修次数 | **0**（4 刀存疑，用户听过说不动） |

## 这份案例最值钱的地方：它自己拆自己的台

前三份的漂亮数字都来自「切点用能量法定、字头也用能量法测」——**同源**。
这一版把这件事摊开写了，而且是做这件事的人自己写的：

> 「这次 A 中位 35ms 有一点循环论证——切点用能量法定，体检的字头也是能量法检测的，两边同源。
> 数字漂亮只能说明『切点落在能量上升沿上』，证明不了落在人耳的字头上。
> **真正的独立验收，是用户复听后说不用挪。**」

所以技能里对这次的结论是**「不记」**：字幕比唱早 0.24s、A 中位 35ms 都不许当证据用
（前者与已有 LRC 条目同源，只是第二个数据点；后者循环论证）。

这是个好示范：**指标能说明「我按自己的定义做对了」，说明不了「你听着对」。后者只能你来说。**

## 烧录字幕这条路怎么走（三步，已进技能）

| 步 | 做法 | 关键 |
|---|---|---|
| 1 | 找歌词 | **画面烧录字幕 → UP 主字幕轨 → 歌词站只做交叉核对**。第一版按搜索摘要写，用户当场判「不对」 |
| 2 | 定句界 | `scripts/burned_subtitles.py` 纯红填充掩码 + 中心窄带，逐帧判 ON/OFF，出 37 段 |
| 3 | 落刀 | 字幕**不当切点**：字幕起点普遍比唱早 **0.17–0.27s**，用它缩窗，再按该句自己的能量谷定刀 |

两个会骗人的地方（技能里也记了）：
- 只改一个字的换行（「快乐小神仙 → 快乐小少年」）像素量几乎不变，会把两句并成一段——必须按 1 秒抽帧用眼睛读；
- 搜索摘要与歌词站会**串歌**：《快乐星球》同剧有四首（《快乐小神仙》《月亮船》《小小少年》《梦幻童年》），第一版就栽在这。

## 「一遍过」指的是切点，不是过程

这份的真实过程并不顺，写清楚免得误导：

| 环节 | 实际情况 |
|---|---|
| 找歌词 | 第一版是二手拼接版，被指出歌词不对，打回 |
| 跑片 | 两次撞上工具调用轮数上限，被中断 |
| 交付 | 首轮只落了成片，镜头表/自检报告/首帧图延后一轮才补 |
| 切点 | **一次定稿，0 返修** ← 这才是「一遍过」 |
| 4 刀存疑 | +252 / −291 / −208 / +184ms，全是无气口的连唱句；交付后复听，没有要求挪 |
